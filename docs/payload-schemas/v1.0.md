## v1.0

### Envelope

```json
{
  "version": "fse.v1.0",
  "origin": "string",
  "id": "string (UUID)",
  "submitted_at": "string (ISO 8601)",
  "data": { ... }
}
```

### Fields

| Field | Type | Description |
|-------|------|-------------|
| `version` | string | Schema identifier (`fse.v1.0`) |
| `origin` | string | Form origin from config (e.g., `contact-form`) |
| `id` | string | UUID — unique per submission |
| `submitted_at` | string | ISO 8601 timestamp |
| `data` | object | Decrypted form fields |
